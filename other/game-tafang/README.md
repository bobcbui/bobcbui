# 保卫大萝卜 (Carrot Fantasy Edition)

一款专为手机与移动端优化的经典萌趣 2D 策略塔防游戏。

## 🌟 核心特色与保卫萝卜经典机制

### 1. 终点萌态大萝卜 (10 HP 互动主角)
- **大萝卜** 坐镇终点基地，拥有 10 点生命（10/10 HP）。
- **动态表情**：
  - 满血健康（10 HP）：欢快大笑、眨眼摇摆、红润腮红。
  - 受伤流汗（4-7 HP）：紧张流汗、咬紧牙关。
  - 濒危咬痕（1-3 HP）：泪眼汪汪、带咬痕切角。
- **趣味互动**：点击大萝卜，大萝卜会 Q 弹跳动并发出萌萌叫声！

### 2. 全图可破坏道具与打宝开荒 (Obstacle Clearing)
- 地图各处散落着**大松树 🌲、巨石 🪨、彩虹蘑菇 🍄、童话小屋 🏠、神秘宝箱 🎁**。
- 清除障碍物不仅能获得丰厚金币（宝箱可开出 80+ 金币），还能在原处**开辟出全新的炮塔建造空地**！

### 3. 点击锁定集火系统 (Target Lock 🎯)
- 玩家随时点击地图上的**任意怪物（如快速怪、Boss）**或**任意道具障碍物**。
- 目标头顶会出现动态闪烁的 **🎯 红色瞄准光圈**，射程内的所有防御塔立即转火优先集火！

### 4. 经典《保卫萝卜》萌趣防御塔
1. 🍼 **瓶子炮**：单体高频射击，造价低廉，满级提供周围 25% 攻速增益光环！
2. 💩 **便便塔**：投掷黏糊糊的便便泥浆，强力单体与小范围减速。
3. 🌻 **太阳花**：360° 环形扩散灼热光波，快速清除周围成片怪物与障碍物。
4. 🪭 **风扇塔**：发射高速旋转飞叶风刃，直线贯穿整条道路上的所有敌人。
5. 🔮 **魔法球**：同时发射 1~3 道追踪魔法光束，锁定多个目标持续电击。
6. 🚀 **火箭炮**：发射超远程追踪穿甲火箭，命中产生巨大爆炸与眩晕。

### 5. 呆萌怪物图鉴
- 🍮 **粉红果冻怪**：蹦蹦跳跳的基础萌怪。
- ⚡ **疾风呆呆鸭**：头顶小风车的高速飞毛腿。
- 🐷 **笨笨巨力猪**：肉嘟嘟的高血量重装大块头。
- 🛸 **漂浮飞碟怪**：自带晶蓝能量护盾的漂浮怪。
- 👻 **调皮小幽灵**：受到攻击触发疾跑爆发。
- 👑 **巨型大萌王**：戴着皇冠的超级关卡守底大魔王。

### 6. 辅助战术与音效
- **萝卜魔法技能**：全场大爆破 💣、全场冰冻 ❄️、萝卜福袋 🎁。
- **倍速与自动连战**：1x / 2x / 3x 倍速自由切换 + 自动下一波连战。
- **Web Audio 萌趣合成音效**：萝卜叫声、清脆金币、便便噗噗声、太阳花呼呼声。

## 🎮 如何游玩
在现代浏览器中直接打开 `index.html` 即可畅玩！
