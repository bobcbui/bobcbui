# 保卫圣女 (Defend the Saintess)

**魔族妖人来袭，请少侠布阵护法，誓死保卫我方圣女！**

一款专为手机与移动端优化的东方仙侠修仙题材 2D 策略塔防游戏。

---

## 🌸 核心特色与仙侠降妖机制

### 1. 终点守护主角：我方纯阳圣女 (10/10 灵力)
- **纯阳圣女** 坐镇终点仙坛，身披流云仙裳、脚踏粉金莲台，拥有 10 点神圣灵力。
- **神态与护盾**：
  - 灵力充沛（10 HP）：圣光金轮环绕、莲花飞舞、闭目浅笑。
  - 受惊御敌（4-7 HP）：双手合十结印御敌、微带汗珠。
  - 护体危殆（1-3 HP）：护体金光破碎、圣女蹙眉祈福。
- **趣味互动**：点击圣女大人，莲台欢快跳跃，散发祥瑞光华，并附带专属仙音与祝福语（“誓死保卫圣女大人！”、“愿圣光庇佑诸位少侠！”）。

### 2. 仙家 6 大护法灵塔体系
1. 🗡️ **飞剑塔**：施展御剑术高频单体穿刺，造价亲民，满级触发“万剑归宗”光环，提升周围法塔 25% 攻速！
2. 🪨 **玄龟镇魔塔**：引玄龟重水形成重力迟滞泥沼，对魔族妖人造成极强减速！
3. ☀️ **九阳真火塔**：360° 环形扩散纯阳三昧真火波，持续焚烧周围成片妖人与灵物障碍，大面积清图除魔神塔！
4. 🌀 **乾坤宝扇**：挥舞太虚风雷宝扇发射狂风罡刃，直线全屏穿透整条小径上的妖邪！
5. 🔮 **五行紫雷珠**：引九天紫霄玄雷，同时多目标锁定电击 1~3 个魔族敌人！
6. 🚀 **诛仙天火弩**：超远程追踪诛仙天火神雷矢，命中产生天翻地覆的巨大范围灵爆！

### 3. 魔族妖人军团图鉴
- 🦇 **魔界小蝠妖**：蹦蹦跳跳的基础魔物。
- 🐺 **疾风魔狼**：迅捷如电的高速冲刺魔兽。
- 🐗 **狂暴猪妖**：皮糙肉厚、自带护甲减伤的肉盾魔怪。
- 🛸 **幽冥邪灵**：自带幽冥护盾的悬浮妖物。
- 👻 **魅影妖狐**：受击时短暂激发展开疾跑突进。
- 👑 **九幽魔尊 Boss**：头戴魔神王冠、拥有海量生命与护盾的终极魔界首领！

### 4. 灵山封魔障碍与宝匣打宝
- 地图各处散落着**千年古松 🌲、封魔巨石 🪨、九转灵芝 🍄、镇魔古刹 ⛩️、玄天宝匣 🎁**。
- 点击任意障碍可附上 **🎯 诛邪锁定** 光圈集火攻击，击破后爆出巨量灵石并开辟全新布阵法位！

### 5. 圣女仙法技能与控制
- ⚡ **九天玄雷**（40 灵石）：引天雷震落全场高伤。
- ❄️ **玄冰定身法**（30 灵石）：全场绝对冰封迟滞 4.5 秒。
- 🌸 **圣女祈福**（20 灵石）：祈天恩赐大量备战灵石。
- **倍速与自动除魔**：1x / 2x / 3x 倍速自由切换 + 自动下一波连战。
