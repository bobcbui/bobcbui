后端工程

后端负责处理数据、业务规则和服务之间的协作。学习后端时，除了会写接口，还要关注可靠性、安全性、可观察性和维护成本。

核心主题

  • API 设计：资源、请求方法、状态码、分页和错误响应。
  • 数据存储：表结构、查询、事务、索引和备份。
  • 服务质量：超时、重试、限流、幂等和降级。
  • 安全边界：认证、授权、输入校验和敏感数据保护。
  • 部署运维：配置、日志、监控、发布和回滚。

从一个小服务开始

  1. 先定义一个清晰的数据模型和最小功能。
  2. 实现正常请求，再补充参数错误和资源不存在等情况。
  3. 为关键逻辑写测试，并记录足够定位问题的日志。
  4. 在本地、测试环境和生产环境使用明确的配置边界。

真正的工程能力体现在系统出错时仍然可理解、可定位、可恢复，而不仅是接口在演示环境里返回了正确结果。
