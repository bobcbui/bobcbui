后端工程

后端负责处理数据、业务规则和服务协作。除了写接口，还要关注可靠性、安全性、可观察性和维护成本。

SHIP WITH CONFIDENCE让系统可理解、可恢复正常路径要跑通，异常路径也要有答案。
学习总览编程学习计算机基础AI 与工具
01

后端核心主题

把接口背后的数据和运行环境一起考虑。

API 设计资源、方法、状态码和分页。
数据存储表结构、查询、索引和事务。
身份安全认证、授权、校验和敏感数据。
可靠性超时、重试、限流和幂等。
可观察性日志、指标、追踪和告警。
部署发布配置、环境、回滚和备份。
02

从小服务开始

把功能做成一个完整闭环。

  • 定义数据模型
  • 设计最小 API
  • 处理错误输入
  • 补测试与日志
03

接口检查表

每个接口都要回答这些问题。

  • 谁可以调用，能访问哪些数据？
  • 参数缺失或格式错误如何响应？
  • 重复请求会不会造成重复写入？
  • 依赖服务失败时能否及时返回？
04

工程质量

演示环境能返回结果，只是起点。

  • 让配置和代码分离，避免把密钥写进仓库。
  • 为关键路径保留结构化日志，方便定位问题。
  • 为数据变更准备备份、迁移和恢复策略。
  • 为外部调用设置超时，避免请求无限等待。
  • 让发布过程可重复，并准备明确的回滚方式。
  • 监控真正影响用户的指标，而不是只收集数字。
