编程学习

编程学习的核心不是记住更多语法，而是把问题拆开、建立清晰的模型，再用代码验证自己的想法。

学习顺序

  1. 语言基础：变量、函数、条件、循环、模块和错误处理。
  2. 数据结构：数组、对象、栈、队列、集合和映射。
  3. 程序设计：拆分职责、复用逻辑、组织文件和维护状态。
  4. 工程实践：Git、测试、日志、配置管理和部署。

适合练习的项目

  • 命令行记事本：练习文件读写、参数解析和数据持久化。
  • 待办清单：练习表单、状态管理、筛选和本地存储。
  • API 小服务：练习路由、参数校验、数据库和错误响应。
  • 个人知识库：练习内容组织、搜索、部署和持续更新。

遇到 Bug 时

先稳定复现，再缩小范围；记录输入、预期结果和实际结果；一次只改一个变量。调试过程本身就是理解程序运行规律的过程。
